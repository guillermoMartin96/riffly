# M1 Proof checklist
- [ ] Local startup commands and supported environment recorded
- [ ] Frontend/backend unit and integration test commands and results
- [ ] Browser E2E record/save/reload/replay demonstration
- [ ] Permission-denied and missing-device scenarios
- [ ] Recorded source audio integrity and duration verification
- [ ] Real inference demonstration (not fixture data)
- [ ] Benchmark dataset and annotation provenance
- [ ] Note precision/recall/F1, onset tolerance, pitch error, processing-time measurements
- [ ] String/fret ambiguity and unsupported-technique disclosure
- [ ] Riff interval boundaries, looping, persistence, deletion semantics
- [ ] Security/privacy review and upload/retention description
- [ ] Independent review findings resolved or explicitly accepted

Record actual commands, outputs, environment, timestamps, and links to evidence. Never precheck without running.
